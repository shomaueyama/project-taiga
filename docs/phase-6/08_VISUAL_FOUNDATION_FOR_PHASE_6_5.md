# Visual Foundation for Phase 6.5

Phase 6 intentionally avoids the cosmic redesign. It prepares a stable foundation for it.

## Tokens

The frontend stylesheet defines semantic tokens:

- `surface`
- `surface-muted`
- `text-primary`
- `text-secondary`
- `border`
- `accent`
- `success`
- `warning`
- `danger`
- `focus`
- spacing tokens from `space-1` to `space-6`
- radius tokens `radius-sm` and `radius-md`

## Layout

- Main content width is constrained to 1180px.
- Sidebar/content layout switches to a single column below 900px.
- Compact mobile adjustments apply below 520px.
- Cards keep radius at 8px or less.

## Deferred to Phase 6.5

- Cosmic palette.
- Space backgrounds.
- Generated or custom visual assets.
- Major animation.
- Screen-by-screen visual redesign.
