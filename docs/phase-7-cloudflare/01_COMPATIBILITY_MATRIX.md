# Compatibility Matrix

| Area | Current implementation | Cloudflare target | Compatibility | Required change | Risk | Evidence |
|---|---|---|---|---|---|---|
| Frontend build | React 19, TypeScript, Vite | Worker static assets or Pages | Compatible with minor changes | Build output can be served from Cloudflare; API base URL should become same-origin or configured per environment. | Low | `frontend/package.json`, `frontend/src/shared/api/client.ts` |
| API runtime | Python 3.13 FastAPI served by Uvicorn | Cloudflare Workers JavaScript/TypeScript runtime | Not suitable | Reimplement API routes in Worker/Hono/itty-router or use a non-Cloudflare Python host. | Critical | `backend/pyproject.toml`, `backend/src/taiga/main.py` |
| ORM/database driver | SQLAlchemy 2 with `psycopg` TCP PostgreSQL driver | D1 binding SQL API | Not suitable | Introduce repository abstraction and D1-compatible SQL implementation. | High | `backend/src/taiga/infrastructure/database.py` |
| Schema | PostgreSQL extension, enum types, `uuid`, `jsonb`, `timestamptz`, `inet`, partial indexes | SQLite-compatible D1 schema | Requires refactor | Convert types to text/integer, JSON text, SQLite checks, application-generated UUIDs, D1 indexes. | High | `backend/alembic/versions/0001_initial_schema.py` |
| Migrations | Alembic executes PostgreSQL DDL | Wrangler D1 SQL migrations | Requires refactor | Add D1 migration set. Keep Alembic for local/AWS PostgreSQL until cutover. | High | `backend/alembic/versions/0001_initial_schema.py`, `backend/alembic/versions/0002_phase5_performance_indexes.py` |
| Transactions | SQLAlchemy request-scoped commit/rollback | D1 explicit batched statements or transaction API | Requires refactor | Preserve atomic flows for submission creation, exam reservation, review updates. | High | `backend/src/taiga/infrastructure/database.py`, `backend/src/taiga/submission_service.py`, `backend/src/taiga/exam_service.py` |
| Row locks | `FOR UPDATE`, `FOR UPDATE SKIP LOCKED` | D1/SQLite has no PostgreSQL row-lock syntax | Requires refactor | Use optimistic locking, unique constraints, Durable Objects for single-writer paths, or Queue semantics. | High | `backend/src/taiga/submission_service.py:236`, `backend/src/taiga/exam_service.py:83`, `backend/src/taiga/runner_jobs.py:129` |
| JSON queries | PostgreSQL `jsonb`, `->>` operators, `CAST(... AS jsonb)` | SQLite JSON text and JSON functions | Requires refactor | Store JSON as text and parse in application, or use SQLite JSON functions where supported. | Medium | `backend/src/taiga/exam_service.py:50`, `backend/src/taiga/curriculum_seed.py` |
| Upload metadata | DB rows plus local filesystem manifest | D1 metadata plus R2 objects | Requires refactor | Replace `file://` upload URLs and local `Path.write_text` with R2 signed upload/read flow. | High | `backend/src/taiga/submission_service.py:66`, `backend/src/taiga/submission_service.py:220` |
| Hidden tests | Local hidden test files under `local-storage/hidden-tests` | R2 private objects | Requires refactor | Store hidden tests in private R2 keys and never expose object contents to learners. | High | `backend/src/taiga/curriculum_seed.py:594` |
| Worker process | Infinite Python loop polling transactional outbox | Queue consumer or Cron Trigger | Requires refactor | Replace polling loop with Queue producer/consumer and retry metadata. | Medium | `backend/src/taiga/worker.py`, `backend/src/taiga/runner_jobs.py` |

| Authentication | LocalAuth via `Authorization: Bearer local:<email>` | Cloudflare Access, OIDC, or Worker session | Requires refactor | Replace LocalAuth before production; define roles and session persistence. | Critical | `backend/src/taiga/auth.py`, `frontend/src/shared/api/client.ts` |
| Authorization | Role checks in Python services | Worker API middleware/domain service | Requires refactor | Port role checks and IDOR protections to Worker implementation. | Medium | `backend/src/taiga/authorization.py`, service modules |
| Rate limiting | In-process Python memory map | Cloudflare WAF/Rules/Turnstile/Durable Object/KV | Requires refactor | Use platform controls or distributed state; in-memory state is per isolate. | Medium | `backend/src/taiga/security.py` |

| WebSocket/SSE | No usage found | Not required | Compatible | No change. | Low | `rg EventSource WebSocket frontend/src backend/src` |
| Email/external APIs | No production email integration found | Not required initially | Compatible | Keep out of initial scope. | Low | `backend/src/taiga/admin_service.py`, `backend/src/taiga/api_schemas.py` |
