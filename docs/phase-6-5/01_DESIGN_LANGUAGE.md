# TAIGA NOVA Design Language

## Brand

- User-facing product name: TAIGA NOVA.
- Development name remains Project Taiga in repository and internal documents.
- Brand role: calm mission control for a practical learning journey.

## Tokens

Implemented in `frontend/src/styles.css`.

- Foundation colors: warm canvas, deep navy, muted blue, beige, brown, yellow, green, orange, red.
- Semantic tokens: background, surface, text, border, primary, accent, info, success, warning,
  danger.
- Typography: Japanese-first system stack with stable line heights and tabular numerals.
- Spacing: 8-point scale with limited 4-point exceptions.
- Radius: 8, 12, 18, 24, and pill.
- Shadows: subtle small/medium elevations only.
- Motion: 120ms and 180ms transitions; reduced motion disables transitions.
