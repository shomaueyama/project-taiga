# Phase 8 Handoff

Phase 8 should focus on approved staging deployment and release readiness.

Inputs from Phase 7:

- Terraform module and environment roots under `infra/`.
- Deployment scripts under `infra/scripts/`.
- CI validation for Terraform and Docker build.
- Runbooks and ADRs under `docs/phase-7` and `docs/adr`.

Do not enable production runner execution until a separate isolated runner design passes
security review.
